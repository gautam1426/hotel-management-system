
# Hotel Management System

## Description
A comprehensive hotel management system built with Python for managing reservations, guest information, room inventory, and billing operations.

## Features
- **Guest Management**: Register and manage guest profiles
- **Room Management**: Track room availability, types, and pricing
- **Reservations**: Create, modify, and cancel bookings
- **Billing**: Generate invoices and manage payments
- **Reporting**: View occupancy and revenue reports

## Installation
```bash
git clone https://github.com/gautam1426/hotel-management-system.git
cd hotel-management-system
pip install -r requirements.txt
```

## Usage
```bash
python main.py
```
